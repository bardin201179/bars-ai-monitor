# Bars AI — внешний монитор

Проверяет `https://bardinsa.ru/ai-agent/api/health` каждые 5 минут и пишет в Telegram,
если сайт не отвечает (и когда снова поднялся).

Работает на GitHub Actions, поэтому проверка идёт снаружи: если упадёт сервер,
хостинг или DNS, сообщение всё равно придёт.

## Секреты репозитория

`Settings` → `Secrets and variables` → `Actions`:

| Секрет | Значение |
|---|---|
| `TELEGRAM_TOKEN` | токен бота `@bars_ai_alerts_bot` |
| `TELEGRAM_CHAT` | `648129181` |

## Как это устроено

- `schedule` раз в 5 минут плюс кнопка ручного запуска (`Run workflow`).
- Если код ответа не `200` — job падает, бот получает сообщение.
- Перед отправкой скрипт смотрит результат предыдущего запуска: пока сайт лежит,
  сообщение не повторяется каждые 5 минут. После восстановления приходит одно
  сообщение «снова отвечает».

## Важное ограничение

GitHub отключает расписания в публичных репозиториях после 60 дней без коммитов.
Раз в месяц нужно делать любой коммит (или включить workflow заново на вкладке Actions).
